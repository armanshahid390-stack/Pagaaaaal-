DUMBOOO'S ANIMATED BIRTHDAY CAKE

Everything (HTML, CSS, JavaScript) is inside index.html.

Preview: open index.html in a browser.

Publish free with GitHub Pages:
1. Create a public repository on https://github.com/
2. Upload index.html to the repository root.
3. Go to Settings > Pages.
4. Select Deploy from a branch, choose main and /(root), then Save.
5. Wait for the Pages URL and share it with Dumbooo.

Optional music: add a royalty-free audio file named music.mp3 beside index.html. The visitor must tap Music to start it.
